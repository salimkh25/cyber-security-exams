# מאגר שאלות – מבוא לאבטחת סייבר

## הדרך הקלה: app.html
לחיצה כפולה על app.html פותחת את האפליקציה בדפדפן. בלי טרמינל.
- **מבחן חדש** – בוחרים מספר שאלות, נושאים, שנים וטיימר, ואז:
  - **מבחן דיגיטלי** – עונים (גם בדף קידוד בצד), מגישים, ומקבלים ציון, פירוט לפי נושא וסקירת טעויות.
    כפתור "מבחן חוזר על השאלות שפספסתי".
  - **תרגול** – משוב מיידי אחרי כל תשובה.
  - **גרסאות להדפסה** – כמה גרסאות מעורבבות + מפתח תשובות (הדפס / שמור כ-PDF).
- **מאגר השאלות** – חיפוש וסינון של כל השאלות, עם אפשרות להציג תשובות.
- **סטטיסטיקה** – מה חוזר בין מבחנים, וריאציות, טענות שחוזרות, חלוקה לנושאים (clustering),
  נושאים לאורך השנים, והביצועים שלך לפי נושא.
היסטוריית המבחנים נשמרת בדפדפן שבו פתחת את הקובץ.

## עדכון המאגר (למשל אחרי הוספת מבחנים לתיקייה)
```
pip3 install pdfplumber numpy
python3 build_bank.py .. -o bank.json
```
הפקודה מחלצת את השאלות, מאחדת כפילויות, מחלקת לנושאים, מנתחת חזרות, ובונה מחדש את app.html.

## קבצים
- build_bank.py – חילוץ שאלות מה-PDF (תשובה א = נכונה; במאגר היא תמיד options[0])
- extract.py – חילוץ טקסט עברי/אנגלי מ-PDF בסדר הנכון
- topics.py – חלוקה לנושאים: TF-IDF + K-Means מעוגן (9 נושאים), וריאציות וטענות שחוזרות
- build_app.py + app_template.html – בניית האפליקציה
- make_exam.py – יצירת מבחנים מהטרמינל (אופציונלי, אותן אפשרויות כמו באפליקציה)
- fixes.json – תיקונים ידניים (קוד, טבלאות, נוסחאות) ושיוך נושא ידני. מוחלים בכל בנייה מחדש.
  מפתח: `שם-קובץ#מספר-שאלה`. אפשר גם `"exclude": true` או `"topic": "שם נושא"`.
