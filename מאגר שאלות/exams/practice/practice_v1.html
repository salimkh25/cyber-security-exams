  1. א.
    It is hard to find messages m0 ≠ m1 such that h(m0) ≠ h(m1)
  2. ב.
    It is hard to find messages m0 ≠ m1 such that h(m0) = h(m1)
  3. ג.
    Given a random message m0, it is hard to find a message m1 that is not equal to m0 such that h(m0) = h(m1)
  4. ד.
    Given a digest d of a random message, it is hard to find a message m such that d = h(m)

מהי התקפת blind sql injection?
  1. א.
    התוקף משתמש בדפדפנים של הקורבנות לביצוע התקפתה מסוג sql injection, כך שהשרת לא יודע מי התוקף, כלומר, עיוור.

    התוקף מבצע ניסוי וטעיה של התקפות שונות מפני שאינו יכול (blind) לבצע התקפות מסוג sql injection. ההתקפות הללו שייכות למשפחות התקפות אחרות, למשל XSS ו CSRF
  3. ג.

    התוקף אינו מקבל את הפלט המקורי של הרצת השאילתא מהשרת, ולכן בונה את השאילתא באופן כזה שבדרך "עקיפה" יבין האם התשובה לשאילתא היא נכונה או לא. (מנגנון של True/false)
