שאלה 3
מה מבין הבאים היא ההגדרה של תכונת ה pre image resistance?
  1. א.
    It is hard to find messages m0 ≠ m1 s.t. h(m0) ≠ h(m1)
  2. ב.
    Given a random message m0, it is hard to find a message m1 that is not equal to m0 s.t. h(m0) = h(m1)
  3. ג.
    It is hard to find messages m0 ≠ m1 s.t. h(m0) = h(m1)
  4. ד.
    Given a digest d of a random message, it is hard to find a message m s.t. d = h(m)

שאלה 5
איזה מהתרחישים הבאים ייחסמו על ידי מנגנון ה Same Origin Policy?
  1. א.
    סקריפט זדוני שהוחדר לעמוד שהגיע מ foo.com ושולח את פרטי הcookie של הקורבן אל bar.com
  2. ב.
    משתמש גלש לאתר foo.com ובאתר זה ישנו סקריפט ששולח טופס אל הדומיין bar.com שאליו המשתמש מחובר (ולכן הדפדפן צירף את ה cookie של המשתמש לבקשה)
  3. ג.
    סקריפט שהגיע מ foo.com (זה ה origin של הסקריפט) מנסה לקרוא תוכן של תשובת http שמגיעה מ bar.com
  4. ד.
    עמוד שהגיע מ foo.com מנסה לטעון תמונה מהדומיין bar.com

שאלה 8
תכונת ה second pre image resistance מוגדרת כ:
  1. א.
    בהינתן הודעה אקראית m, קשה למצוא הודעה m’ ששונה מ m, כך ש h(m) = h(m’)
  2. ב.
    בהינתן הודעה אקראית m, קשה למצוא הודעה m’ ששונה מ m, כך ש h(m) שונה מ h(m’)
  3. ג.
    בהינתן digest d של הודעה אקראית, קשה למצוא הודעה m כך ש h(m)=d
  4. ד.
    בהינתן digest d של הודעה אקראית, קשה למצוא digest d’ כך ש d שונה מ d’
שאלה 9
מה תפקידו של מנגנון OCSP stapling?
  1. א.
    לאפשר לשרת אינטרנט לשלוח ללקוח את הסטטוס המעודכן של התעודה של השרת (אם בוטלה או לא), בלי שהלקוח יצטרך לפנות בעצמו לשרת ה OCSP.
  2. ב.
    לייתר את הצורך לבדוק את ה chain of trust.
  3. ג.
    מדובר במנגנון challenge הנועד לוודא ששרת אינטרנט שפנה ל CA בטענה לבעלים של דומיין מסויים הוא אכן הבעלים של הדומיין הזה.
  4. ד.
    לאחסן רשימה של כל התעודות שה CA ביטל.
