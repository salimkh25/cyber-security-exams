שאלה 1
איזו מבין הטענות הבאות נכונה?
  1. א.
    בביטקוין, מנגנון ה escrow transactions מחייב כל miner ״לנעול״ בערבון מספיק ביטקוין מראש כך שאם ייתפס שהminer איפשר לתוקף לבצע double spending ינקו את הקנס מהערבון של ה miner.
  2. ב.
    בביטקוין, חובה לכרות ביטקוין בעצמנו אם אנחנו רוצים לבצע עסקאות בביטקוין
  3. ג.
    בביטקוין, לא משתמשים ב One Time Pad בכדי לייצר את הארנקים
  4. ד.
    ב escrow transactions, המוכר חייב לאשר את העסקה כדי שהיא תהיה חוקית

  2. ב.

  3. ג.
    סקריפט שהגיע מ foo.com (זה ה origin של הסקריפט) מנסה לקרוא תוכן של תשובת http שמגיעה מ bar.com
  4. ד.
    סקריפט זדוני שהוחדר לעמוד שהגיע מ foo.com ושולח את פרטי הcookie של הקורבן אל bar.com
שאלה 4
אלגוריתם 3DES יכול לתמוך אחורה בהצפנת DES. נתונים שלושה מפתחות K1, K2, K3. כיצד מוגדרת פעולת ההצפנה ב 3DES שתאפשר הצפנה גם עבור 3DES וגם תאפשר תמיכה אחורה בצופן DES המקורי?
  1. א.
    C = EncK3(DecK2(EncK1(m)))
  2. ב.
    C = EncK3(DecK2(DecK1(m)))
  3. ג.
    C = DecK1(EncK2(EncK3(m)))
  4. ד.
    C = DecK1(DecK2(DecK3(m)))
