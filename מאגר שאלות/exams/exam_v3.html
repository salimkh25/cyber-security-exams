שאלה 1
אליס רוצה לשלוח הודעות לבוב, ושבוב יוכל לוודא ששתי הדרישות הבאות מתקיימות:
א) ההודעה הגיעה אליו בדיוק כפי שאליס שלחה אותה. ב) אליס אכן חיברה את ההודעה. נתון שבוב ואליס כבר החליפו ביניהם בצורה מאובטחת את כל סוגי המפתחות הנדרשים לתהליך. מה תשלח אליס לבוב?
  1. א.
    את ההודעה מוצפנת במפתח הסימטרי המשותף ביניהם.
  2. ב.
    את ההודעה + MAC על ההודעה.
  3. ג.
    את ההודעה + חתימה דיגיטלית בעזרת המפתח הפומבי של בוב.
  4. ד.
    את ההודעה מוצפנת במפתח הפומבי של בוב.
שאלה 2
נתון דף אינטרנט שמוצג בגלישה לURL הבא:
http://foo.com/?name=VALUE
הדף מציג את הערך של הפרמטר name ישירות בתוך תגית HTML כך:
<div id="greeting">Welcome, VALUE</div>
ללא כל סינון או קידוד של התוכן שמגיע מה-URL.
בנוסף, בדף יש טופס עם Anti-CSRF Token שמוצג בטופס כך:
<form method="POST" action="/update_password">
<input type="hidden" name="csrf_token" value="random_token_value">
<input type="password" name="new_password">
<input type="submit" value="Submit">
</form>
כאשר במקום random_token_value יופיע token אקראי שהשרת בחר.
איזו מהטענות הבאות אינה נכונה?
  1. א.
    ה-CSRF Token לא יכול להיגנב כי הוא ב-POST בלבד ולא ב-URL
  2. ב.
    גניבת ה-csrf_token מאפשרת לתוקף לבצע בקשות POST עם טוקן תקין שהשרת יקבל כתקין
  3. ג.
    הדף פגיע ל-Reflected XSS מכיוון שהפרמטר name מוצג ללא סינון
  4. ד.
    תוקף יכול להזריק קוד JavaScript ב-name ולגנוב את ה-csrf_token מהטופס
שאלה 3
ב TLS, נתון כי תוקף Man in the middle החליף תו בהודעת ה ClientHello שהלקוח שלח לשרת. מה השלב המוקדם ביותר שזה יתגלה?
  1. א.
    מיד לאחר שה ClientKeyExchange הגיע לשרת
  2. ב.
    מיד לאחר שה ServerHello הגיע ללקוח
  3. ג.
    מיד לאחר שה ClientHello הגיע לשרת
  4. ד.
    מיד לאחר שה ClientFinish הגיע לשרת
שאלה 4
איזה מהתרחישים הבאים ייחסמו על ידי מנגנון ה Same Origin Policy?
  1. א.
    סקריפט זדוני שהוחדר לעמוד שהגיע מ foo.com ושולח את פרטי הcookie של הקורבן אל bar.com
  2. ב.
    עמוד שהגיע מ foo.com מנסה לטעון תמונה מהדומיין bar.com
  3. ג.
    סקריפט שהגיע מ foo.com (זה ה origin של הסקריפט) מנסה לקרוא תוכן של תשובת http שמגיעה מ bar.com
  4. ד.
    משתמש גלש לאתר foo.com ובאתר זה ישנו סקריפט ששולח טופס אל הדומיין bar.com שאליו המשתמש מחובר (ולכן הדפדפן צירף את ה cookie של המשתמש לבקשה)
שאלה 5
איזו טענה אינה נכונה?
  1. א.
    מנגנון Certificate Transparency ומנגנון Certificate Revocation List (CRL) פותרים בעיות שונות
  2. ב.
    מנגנון ה Online Certificate Status Protocols (OCSP) ו מנגנון ה Certificate Transparency פותרים בעיות שונות
  3. ג.
    מנגנון ה Signed Certificate Timestamp (SCT) נועד לפתור בעיית פרטיות הקיימת במנגנון ה OCSP
  4. ד.
    מנגנון Certificate Transparency בא לידי ביטוי ב certificates על ידי ערכי ה Signed Certificate Timestamp (SCT)
שאלה 6
איזו מהטענות הבאות נכונה?
  1. א.
    אפשר להשתמש בבוטים רק למטרות DDoS.
  2. ב.
    שולחים בקשת DNS מפורט אקראי כדי להקשות על ניחוש הפורט ע"י תוקף.
  3. ג.
    בכדי ש SSL/TLS יגן על מידע רגיש, חובה על הלקוח והשרת להיות מצוידים בתעודה תקנית המוכיחה את זהותם.
  4. ד.
    משתמשים ב DMZ כאשר לא ניתן להשתמש בחומת אש.
שאלה 7
תכונת ה second pre image resistance מוגדרת כ:
  1. א.
    בהינתן הודעה אקראית m, קשה למצוא הודעה m’ ששונה מ m, כך ש h(m) = h(m’)
  2. ב.
    בהינתן digest d של הודעה אקראית, קשה למצוא digest d’ כך ש d שונה מ d’
  3. ג.
    בהינתן הודעה אקראית m, קשה למצוא הודעה m’ ששונה מ m, כך ש h(m) שונה מ h(m’)
  4. ד.
    בהינתן digest d של הודעה אקראית, קשה למצוא הודעה m כך ש h(m)=d
שאלה 8
איזה מהתיאורים הבאים מתאר את התקפת ARP poisoning?
  1. א.
    תוקף מאזין לתעבורת ARP ומזהה הודעות ARP פגיעות, ומחלץ מהן את כתובת ה IP של הקורבנות.
  2. ב.
    תוקף שולח הודעות ARP שקריות בהן הוא משקר לגבי מיפוי בין כתובת MAC ו IP, כדי שהתעבורה של הקורבן תגיע אליו (אל התוקף).
  3. ג.
    תוקף שולח הודעות ARP אל שרת ה DNS המקומי של הרשת, כדי ששרת ה DNS יעבוד כמו hub במקום כמו switch.
  4. ד.
    תוקף שולח הודעות ARP רבות אל ה switch כדי להציף את הטבלה של ה switch במיפויים שקריים.
שאלה 9
נתון הפרוטוקול הבא להעברה של מפתח משותף K מאליס לבוב:
1. אליס מגרילה באקראי מפתח ארוך K.
2. אליס מגרילה מחרוזת KA חד פעמית אקראית באורך |K|.
3. אליס מחשבת את K1 באופן הבא: K1 = K xor KA, ואליס שולחת את K1 לבוב.
4. בוב מגריל מחרוזת KB חד פעמית אקראית באורך |K1|.
5. בוב מחשב את K2 באופן הבא: K2 = K1 xor KB, ושולח לאליס את K2.
6. אליס מחשבת את K3 באופן הבא: K3 = K2 xor KA, ואליס שולחת את K3 לבוב.
7. בוב מחשב: K3 xor KB, ומקבל את K. איזו מהטענות הבאות נכונה?
  1. א.
    הפרוטוקול מוגן כנגד אויב מאזין וגם מוגן כנגד אויב MitM
  2. ב.
    הפרוטוקול מוגן כנגד אויב מאזין אך אינו מוגן כנגד אויב MitM
  3. ג.
    הפרוטוקול מוגן כנגד אויב MitM, בתנאי שהאויב לא יכול לעכב הודעות
  4. ד.
    הפרוטוקול אינו מוגן כנגד אויב מאזין
